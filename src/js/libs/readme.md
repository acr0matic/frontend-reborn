# Подсказка

Библиотеки подключаются через Yarn — эта папка только для редких случаев,
когда файла нет в npm-репозитории или нужна пропатченная версия.

Стили npm-библиотек импортируются в `src/js/app.js` (как `swiper/css`),
расширение и переопределение — в `src/scss/vendors/extend/` и `override/`.
