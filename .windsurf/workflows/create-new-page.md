# Создание новой страницы

**Задача:** Создать новую страницу [НАЗВАНИЕ_СТРАНИЦЫ] в проекте

## Требования

### 1. Создать HTML файл

- **Имя файла:** `[ТИП_СТРАНИЦЫ]-[НАЗВАНИЕ].html` (например: `page-contact.html`, `archive-news.html`, `single-news.html`)
- **Расположение:** `src/`
- **Структура:** аналогично существующим страницам (include head, header, breadcrumbs, footer, section buy/bottom)
- **ID контейнера:** `[ПРЕФИКС]-[НАЗВАНИЕ]` (например: `cp-contact`, `ap-news`, `sp-news`)
- **ID секции контента:** `[ПРЕФИКС]-[НАЗВАНИЕ]-content`
- **Заголовок страницы в H1**

### 2. Создать SCSS файл

- Создать директорию: `src/scss/layout/pages/[ТИП]/[НАЗВАНИЕ]/`
- Имя файла: `_content.scss`
- Базовая структура:
```scss
#[ID-СЕКЦИИ] {
  .content {
    &__[БЛОК] {

    }
  }
}
```

### 3. Добавить импорт

- В файл `src/scss/layout/pages/[ТИП]/_main.scss`
- Добавить строку: `@import "[НАЗВАНИЕ]/content";`

## Типы страниц

- **common** - обычные страницы (page-*.html, префикс cp-)
- **archive** - архивные страницы (archive-*.html, префикс ap-)
- **single** - внутренние страницы (single-*.html, префикс sp-)

## Опционально

- Добавить ссылку на страницу в `src/index.html` для навигации
- Создать дополнительные SCSS файлы для подблоков (например, _callback.scss)

**Важно:** Не заполнять стили и контент - только базовая структура.
